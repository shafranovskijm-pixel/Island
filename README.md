# Island

Systemic 2D island-life RPG prototype in Godot 4.

## Core idea
The player starts as nobody. There is no class selection. Repeated actions, relationships and consequences shape the character.

## v0.2 systemic prototype
- top-down movement
- mobile touch joystick and action button
- day/time simulation
- hunger, energy and coins
- NPC interaction and relationships
- action-based skills
- begging, work, food and drinking
- physical world items
- item ownership
- free item pickup
- theft when taking owned items
- nearby witnesses detect theft
- NPC memory records witnessed crimes
- suspicion and relationship penalties
- reputation and wanted counters
- inventory count
- theft and stealth skills grow through actions
- island landmarks: port and tavern

## Current systemic rule
Items are not quest props. They exist in the world, can have an owner, can be taken by the player, and NPCs can react depending on whether they witness the action. This is the first foundation for emergent stories rather than isolated scripted quests.

## Controls
Desktop: WASD to move, E or Space to interact.

Mobile: left virtual joystick, right action button.
