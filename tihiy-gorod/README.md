# Тихий город

Изометрический город-симулятор на Unity (Built-in Render Pipeline). Игрок выбирает путь — **Добро**, **Тьма**, **Магия** или **Сказка** — и город, свет, погода, жители и музыка меняются вместе с ним.

Проект рассчитан на **Unity 2022.3.62f1 LTS** (откроется и в соседних 2022.3 / Unity 6, но целевая версия — 2022.3 LTS). Редактор на этой машине **не установлен**: откройте папку в Unity Hub у себя.

Старт — **главное меню** (не сразу город): «Играть», «Вечера», «Настройки». Фон — `Assets/StreamingAssets/Art/menu-cozy.png` (тот же файл, что в `Assets/Art/UI/`).

## Что умеет игра (не заглушки)

1. **Пути (alignment)** — выбор основного пути на старте, дерево I → II → III за ресурсы. Соседние здания разных путей дают **гармонию** (цветение, порча, чары, сновидение) или **разлад** (конфликт, дикая тень) — множитель дохода и цветная аура.
2. **Ресурсы** — Дерево, Камень, Сущность + уникальные Свет / Тень / Руны / Сказка. Здания тикают доход, жители приносят чуть-чуть при сборе. Счётчики вверху экрана.
3. **8 зданий** (по 2 на путь) на сетке 10×10. Тап по пустой клетке ставит выбранный тип, если хватает ресурсов. Тап по зданию — улучшение. Формы разные: святилище, сад, склеп, башня, обсерватория, кристалл, грибной круг, сказочный дом.
4. **Автономные жители** (12 штук: поселяне, духи, огоньки). Бродят между зданиями, собирают, ночью идут «домой» с фонарём, в дождь ищут укрытие и надевают капюшон. Цвет зависит от пути города. Команд игрока нет.
5. **День / ночь + дождь.** Полный цикл ~3 минуты. Солнце, небо, туман, окна домов светятся ночью. Дождь: частицы, мокрая земля, глуше музыка, реакция юнитов. Кнопка «Дождь» или случайная погода.
6. **Музыка** — процедурные слои (D Dorian): подложка пути, дневной и ночной мотив, дождевой слой, пульс плотности города. При высоком уюте пад теплее (больше терций). Шкатулка добавляет тихий высокий мотив. Кроссфейд, тишины нет.
7. **Тач** — тап поставить/выбрать, один палец — панорама, щипок — зум. В редакторе: ЛКМ тап, ПКМ/средняя — панорама, колесо — зум.
8. **Bootstrap** — сцена почти пустая: камера, свет, EventSystem, объект Bootstrap. Сначала `GameFlow` показывает меню; город собирается в `Bootstrap.StartWorld` после «Играть» / выбора вечера.
9. **Уют (0–100)** — отдельный счётчик на HUD с иконкой очага. Растёт от уютных предметов каждый тик, медленно остывает. Высокий уют: теплее свет и пад, жители медлят, в дождь окна ярче (как внутри дома). Низкий: ночь жёстче, жители спешат.
10. **Уютные предметы** (вкладка «Уют», не полноценные здания) — на клетку или как пристройка к дому:
    Очаг/камин, самовар (жители пьют чай), плед на лавке (садятся), фонарь (ночь мягче), занавеска (только на здание, свечение), книжная полка, горшок с геранью, музыкальная шкатулка (тихий высокий голос в музыке), спящий кот (крошечный юнит, спит на лавках).
11. **Вечера** — главы, не боёвка. Вечер 1 «Первый огонь» (поставить уют и набрать 20), Вечер 2 «Гости» (принять гостя-загадку), Вечер 3 «Дождь» (укрыть город очагом/фонарём). Баннер, цель, затем следующий вечер. «Играть» продолжает последний вечер.
12. **Гости с загадками** — с вечера 2, первый визит ~45 с, далее ~90 с. Полноэкранный портрет из `StreamingAssets/Art/` (бабушка у очага, Лиат, купец крови, теневой сосед). Народная загадка, три ответа, один верный. Нельзя пропустить сразу. Городской ввод на паузе. Верно: +уют, ресурс, открытие предмета. Неверно: всё равно маленький гостинец.

## Установка и Play

1. Поставьте [Unity Hub](https://unity.com/download).
2. В Hub → **Installs → Install Editor → 2022.3.62f1** (или любой **2022.3 LTS**).
3. Обязательно отметьте модуль **Android Build Support** (SDK, NDK, OpenJDK). Для телефона нужен именно он.
4. **Add → Add project from disk** → укажите эту папку (`tihiy-gorod-unity`).
5. Откройте проект. **Первый импорт долгий** (минуты): Unity генерирует `Library/`. Не закрывайте окно.
6. Дождитесь компиляции скриптов (угол внизу). Откроется сцена `Assets/Scenes/Main`.
7. Нажмите **Play**. Сначала главное меню на тёплом фоне. «Играть» собирает город: сетка, дома, жители, HUD на русском, музыка, выбор пути, вкладки «Постройки | Уют».

Если сцена пустая после Play — смотрите Console: Bootstrap пишет `Тихий город: мир собран`. Если скрипт не привязался, запасной загрузчик создаст Bootstrap сам.

## Сборка APK (Android)

1. Телефон: включите «Отладка по USB» или просто копируйте APK.
2. В Unity: **File → Build Settings**.
3. Платформа **Android** → **Switch Platform** (первый раз тоже долго).
4. Сцена `Assets/Scenes/Main` должна быть в списке Enabled.
5. **Player Settings**:
   - Company: Maxim Shafranovskij
   - Product: Тихий город
   - Package: `com.shafranovskij.tihiygorod`
   - Minimum API 22, архитектуры ARMv7 + ARM64 уже прописаны.
6. **Build** (не Build And Run, если нет USB). Сохраните `TihiyGorod.apk`.
7. Перекиньте APK на телефон и установите (разрешить установку из неизвестных источников).

IL2CPP для Android включён (`scriptingBackend: Android 1`). Первая сборка долгая.

iOS — позже: тот же проект, модуль iOS Build Support, Bundle Id тот же.

## Управление

| Действие | Телефон | Редактор |
| --- | --- | --- |
| Меню | Играть / Вечера / Настройки | то же |
| Выбрать путь | большие кнопки после старта города | то же |
| Поставить здание | вкладка «Постройки», затем тап по клетке | ЛКМ |
| Поставить уют | вкладка «Уют», затем тап по клетке (занавеска — по дому) | ЛКМ |
| Улучшить здание | тап по зданию → «Улучшить» | то же |
| Камера | палец / щипок | ПКМ + колесо |
| Дождь | кнопка «Дождь» | то же |
| Прокачать путь | «Путь I/II/III» | то же |
| Загадка | три кнопки ответа, ждать реплику гостя | то же |

## Известные пробелы

- Здесь нет Unity Editor, поэтому сцена не прогонялась кнопкой Play на этом компьютере.
- Визуал — цветные меши, не авторские модели / тайлы.
- Нет сохранения города (только номер вечера и открытия уюта в PlayerPrefs), тумана войны, мультиплеера.
- Музыка синтезируется в рантайме (не готовый саундтрек WAV).
- Нет URP post-FX (bloom как полноценный эффект камеры). «Цветение» и «порча» — частицы + аура клеток.
- iOS не доведён до TestFlight (только общие Player Settings).
- Шрифт UI — встроенный Arial/Liberation (кириллица есть). Для релиза лучше подключить свой TTF.

Версия редактора в `ProjectSettings/ProjectVersion.txt`: **2022.3.62f1 (4af31df58517)**.
